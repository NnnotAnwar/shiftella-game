# Песочница — «Ночная смена»

> Бесконечные ночи в случайном городке. Здесь нет сюжета, есть **твоя** история: её создают люди, черты характера и Ночь-рассказчик.
> Вся песочница — **[позже]**. MVP = одна бесконечная ночь в фиксированном городе (Млгов) без генерации.

---

## 1. Что делает её переигрываемой

1. **Каждый город — другой поток гостей** (учреждения рядом определяют, кто приходит и когда).
2. **Случайный персонал** — комбинации черт превращают расписание в головоломку «кого с кем ставить».
3. **Характер ночи** (спокойная / хаотичная) меняет темп (events.md §6.4).
4. **Городская легенда** — в каждом городе свой «гость 3:33»: один странный постоянный гость с мини-аркой.
5. **Долгие цели**: уровни репутации, коллекции, сезоны, рост аренды.

---

## 2. Генерация города — параметры

| параметр | варианты | на что влияет |
|---|---|---|
| `seed` | число | всё ниже воспроизводимо (поделиться городом с другом) |
| `name` | генератор: `[префикс] + корень + суффикс` — префиксы «Horní/Dolní/Nová/Stará», корни «Ml-, Vran-, Lip-, Kos-, Bor-, Hruš-», суффиксы «-ov, -ice, -any, -ín, -ná Lhota» | только флейвор, но проверка, что имя не совпало с реальным городом из стоп-листа |
| `size` | деревня / городок / райцентр | базовый поток: 0.6 / 1.0 / 1.5 |
| `station` | полустанок / узловая / конечная | ночные поезда: 0–1 / 2–3 / 1 + шанс `ev_late_train` |
| `institutions` | 2–4 из списка (§3) | какие пулы гостей включены и в какие часы |
| `climate` | сухой / дождливый / туманный | шанс `ev_rain`, `ev_fog`, `ev_storm` |
| `season_start` | весна / лето / осень / зима | стартовая погода; сезон меняется каждые 30 ночей |
| `building` | 3 шаблона плана: «буфет» (узкий), «угловое» (Г-образное), «бывшая касса» (квадрат, без двора) | размер зала, место кухни, есть ли двор |
| `rent` | 800–2 500 Kč/ночь (от `size`) | давление денег |
| `competitor` | нет / заправка NONSTOP / кебаб у вокзала | −10…−25 % гостей своего пула; можно «победить» репутацией ≥ 70 |
| `legend` | 1 из пула городских легенд (§5) | особый странный гость |

## 3. Пулы гостей

| учреждение | пул | часы | что заказывают | терпение | платят | особенность |
|---|---|---|---|---|---|---|
| (всегда) вокзал | `travelers` | весь вечер, пики у поездов | кофе, топинка | среднее | средне | чемоданы занимают место |
| стоянка такси | `taxi` | 23:00–01:00, 03:00–04:00 | `coffee_black` | низкое | ровно + чаевые за скорость | приходят по 1, иногда толпой |
| больница | `medics` | 02:00–02:30, 05:30–06:00 | капучино, суп | низкое | средне | благодарные: отзыв +50 % |
| колледж / общежитие | `students` | 23:30–04:00 | кофе, дешёвое | высокое | мало | сидят долго, хотят розетки и Wi-Fi |
| дом культуры / клуб | `young` | 23:00–01:00 (пт/сб) | всё сразу | низкое | хорошо | толпы, шум, грязь |
| завод / склад в три смены | `workers` | 22:00, 06:00 (пересменка) | суп, хлебичек, много | среднее | хорошо | приходят группой по расписанию |
| трасса / автостоянка фур | `truckers` | 01:00–05:00 | еда, кофе с собой | среднее | хорошо | машины занимают двор |
| полиция / пожарная часть | `uniforms` | 01:00–04:00 | кофе | среднее | ровно | меньше `ev_dine_and_dash` |
| (всегда) жители | `insomniacs` | 00:00–04:00 | чай, колач | высокое | мало | становятся постоянными быстрее всех |

**Постоянные гости:** любой обычный гость, посетивший кафе 5 раз довольным, может стать постоянным (шанс 30 %). Он получает имя, любимый заказ и одну случайную мини-арку из шаблонов:

| шаблон арки | суть | 3 этапа |
|---|---|---|
| `arc_burnout` | устал от работы | заметить → дать тихий угол → решение (остаться/уйти) |
| `arc_exam` | учёба / экзамен | розетка → поддержать в провал → торт-благодарность |
| `arc_lonely` | одиночество | запомнить заказ → свести с другим гостем → «привёл друга» |
| `arc_secret` | что-то скрывает | доверие → признание → выбор игрока |
| `arc_talent` | скрытый талант | заметить → дать сцену/стену → вечер (реп +) |

## 4. Ручки сложности

| ручка | лёгкая | норма | тяжёлая |
|---|---|---|---|
| стартовые деньги | 15 000 Kč | 8 000 | 3 000 |
| рост аренды | нет | +5 % каждые 10 ночей | +10 % каждые 7 ночей |
| терпение гостей | ×1.3 | ×1.0 | ×0.75 |
| вес плохого отзыва | ×0.7 | ×1.0 | ×1.5 |
| износ оборудования | ×0.5 | ×1.0 | ×1.5 |
| угасание потребностей персонала | ×0.8 | ×1.0 | ×1.2 |
| банкротство | никогда (долг копится) | 3 ночи подряд в минус | 2 ночи подряд в минус |
| характер ночи | спокойная / хаотичная / «свои ползунки» (`base_rate`, доля `good`, `uncanny`) | | |

Всё это — числа в `difficulty.ron`. Можно не делать меню: на старте хватит трёх готовых пресетов.

## 5. Городские легенды (странный постоянный гость)

| id | легенда | когда приходит | что нужно | награда за арку |
|---|---|---|---|---|
| `legend_333` | гость в 3:33 (как в сюжете, но без Лиды) | 03:33 | его стол свободен, свет горит | монеты → коллекция; часы «стоят» вечно (декор) |
| `legend_lamplighter` | фонарщик, который зажигает уже несуществующие фонари | 04:44 | лампа на окне | +5 % гостей в туман |
| `legend_conductor` | проводник отменённого поезда | только в туман | «билет» (компостер — мебель) | редкий пул `odd_*` гостей ×2 |
| `legend_letters` | женщина, которая пишет письма и оставляет их неотправленными | 01:11 | почтовый ящик (мебель) | письма → настроение персонала, флейвор-лор города |

## 6. Долгие цели

- **Уровни репутации** (открывают мебель, меню, пулы):
  | реп | титул | открывает |
  |---|---|---|
  | 0–19 | «Забегаловка» | базовое меню |
  | 20–39 | «Своё место» | Wi-Fi, розетки, вторая кофемашина |
  | 40–59 | «Ночной адрес» | сцена, «тихий угол», лицензия на глинтвейн |
  | 60–79 | «Свет у вокзала» | редкие гости, блогеры, туристы |
  | 80–100 | «Легенда города» | своя городская легенда раскрывается полностью |
- **Коллекции:** «Городские легенды» (по 1 за город), «Странные гости» (все `odd_*`), «Книга рецептов» (рецепты от постоянных и `ev_staff_inspired`), «Бюро находок» (забытые вещи).
- **Карьера персонала:** через 30+ ночей сотрудник с навыком 9+ может (а) стать старшим смены (бафф команде) или (б) уйти открывать своё кафе. Тогда в другом городе-сиде он появится как конкурент или друг — мета-связь между партиями.
- **Сезоны:** каждые 30 ночей меняется сезон: погода, пулы (летом больше туристов, зимой — `insomniacs`) и сезонные события.
- **Испытания (челлендж-сиды):** «Без кухни», «Только два сотрудника», «Хаотичная ночь + деревня», «Все неуклюжие».
- **Счёт партии** (для сравнения сидов): ночи без банкротства × средняя репутация + закрытые арки × 100.

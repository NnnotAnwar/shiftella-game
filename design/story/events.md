# События — «Ночь-рассказчик»

> Ночь сама решает, что случится. Ниже 35 событий (часть случайные, часть «авто» — срабатывают от состояния) и правила ритма.
> Как записывать эффекты — traits.md §1. Сюжетные события по номерам ночей описаны в story.md.
> Режим: **S** — сюжет, **P** — песочница, **S+P** — оба. **MVP: да** — 10 штук для первого прототипа (3 из них «авто»).

## 0. Формат одного события

| поле | смысл |
|---|---|
| `id` | уникальный ключ |
| `kind` | `good` / `bad` / `neutral` / `uncanny` — нужно рассказчику для баланса |
| `severity` | 1–3: насколько сильно бьёт (стоимость в «бюджете напряжения») |
| `when` | условия: время, погода, ночь №, черты, состояние |
| `effects` | список эффектов + длительность |
| `weight` | базовый вес в случайном выборе (больше = чаще) |
| `cooldown` | сколько ночей не повторять |

```ron
Event(
    id: "ev_downpour",
    kind: Neutral, severity: 2, weight: 30, cooldown: 2,
    when: [Weather(Rain), TimeBetween("22:30", "03:00")],
    effects: [
        Mul(stat: "guests.rate", value: 2.0, minutes: 120),
        Mul(stat: "dirt.rate", value: 2.0, minutes: 120),
    ],
    text_ru: "Небо прорвало. Половина вокзала прячется у тебя.",
)
```

## 6. Как Ночь ведёт рассказ (ритм)

### 6.1 Бюджет напряжения
- У Ночи есть **`tension`** (0–100). Каждое событие стоит `severity × 10`. `kind=good` — стоимость отрицательная (снижает напряжение).
- Каждую игровую минуту рассказчик бросает кубик: `шанс = base_rate × curve(время) × act_mult(ночь)`.
- Если выпало — выбираем событие по весам из тех, у кого выполнены `when` и не идёт `cooldown`, и чья стоимость влезает в `max_tension − tension`.
- После плохого события — **передышка**: `breath_min` минут без новых `bad`.

### 6.2 Кривая одной ночи (22:00–06:00)

| часы | фаза | что подкручиваем |
|---|---|---|
| 22:00–00:00 | **Разгон** | гостей мало → больше; события лёгкие (`severity ≤ 1`), погода |
| 00:00–02:00 | **Пик** | толпы, концерты, поломки; самая высокая `curve` |
| 02:00–04:00 | **Ведьмин час** | гостей мало; `uncanny` ×3; персонал устал → ошибки ×1.5; ровно 03:33 — `ev_clock_333` |
| 04:00–05:30 | **Спад** | таксисты, патрули; почти нет `bad` |
| 05:30–06:00 | **Рассвет** | пересменка в больнице; только `good`/`neutral`; итоги ночи |

```
curve:  22 ▁▂▃ 00 ▅▇█ 02 ▄▃▃ 04 ▂▂▁ 05:30 ▃ 06
```

### 6.3 Кривая 30 ночей (сюжет)

| ночи | `act_mult` | `max_severity` | идея |
|---|---|---|---|
| 1–3 | 0.3 | 1 | туториал: только `ev_rain`, `ev_big_tip`, `ev_broken_dishes` |
| 4–7 | 0.6 | 2 | первые проблемы, перед платежом №1 — мягче |
| 8–16 | 0.9 | 2 | ровная нагрузка + арки |
| 17–24 | 1.1 | 3 | давление: франшиза, тяжёлые ночи |
| 25–29 | 1.2 | 3 | шторм и развязки, но ≥ 1 «тёплое» событие за ночь |
| 30 | 0.5 | 1 | финальная ночь — про людей, а не про поломки |

**Правило платежей:** за 1 ночь до платежа `bad`-события с `severity 3` запрещены. Наказывать игрока за невезение перед дедлайном нельзя.

### 6.4 Характер ночи: спокойная / хаотичная (песочница; сюжет = «спокойная+»)

| параметр | спокойная | хаотичная |
|---|---|---|
| `base_rate` (за мин) | 0.004 | 0.009 |
| `max_tension` | 50 | 100 |
| доля `good` | 40 % | 20 % |
| `breath_min` после `bad` | 60 | 15 |
| максимум `bad` подряд | 1 | 3 |
| `uncanny` множитель | ×1 | ×1.5 |
| клапан `ev_lonely_night` | после 2 тяжёлых ночей | выключен |
| помощь при бедности (деньги < 1 дня аренды) | `good` ×2 | нет |
| персонал-события за ночь, максимум | 1 | без лимита |

**Для MVP:** только `base_rate`, `curve(время)`, веса и `cooldown`. Бюджет `tension` и характер ночи — позже.
